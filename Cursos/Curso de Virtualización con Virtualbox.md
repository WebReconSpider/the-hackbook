# 1.Sistemas Operativos
- Un sistema operativo gestiona el hardware y ayuda a los programas a funcionar en un dispositivo. 
- Las funciones principales de un SO incluyen administrar recursos, organizar archivos, controlar periféricos y proporcionar una interfaz de usuario. 
- Se pueden dividir en diferentes grupos: Ordenadores (Windows, Linux, Mac OS), Disp. Móviles (Android, iOS), Código abierto (Android, Linux), Propietario (Windows, Mac OS, iOS) 
Los de código abierto, pueden ser utilizados y modificado libremente. Para usar un propietario, hay que pagar una licencia y no es posible modificar el código.

El resto de SO conocidos, son distribuciones de Linux o usan su Kernel. 

## Linux y GNU: Conceptos Clave

### El Kernel

Analogía: si el ordenador es un **coche**. El Kernel es el motor.

¿Qué hace? Es el intermediario. Controla y gestiona el hardware (memoria, procesador) para que las aplicaciones puedan usarlo.

![[Curso-Virtu-Kernel.png]]

### GNU

 Las herramientas necesarias (editor de texto, compiladores, sistemas de archivos) para tener un sistema operativo completo y libre.

###  La Unión: GNU/Linux

Lo que se instala en un ordenador (como Ubuntu o Debian) es la suma de ambos:

> **GNU** (Herramientas) + **Linux** (Kernel) = **Sistema Operativo Completo**

--- 
### El caso de Android

No todo lo que lleva el Kernel Linux es "GNU/Linux".

- **Android** usa el kernel de Linux.

- Pero no usa las herramientas de GNU. Por eso Android y Ubuntu son tan distintos aunque compartan el mismo "corazón".

---

> [!Tip] Resumen:
> 
> Decimos "Linux" por comodidad, pero el sistema completo es **GNU/Linux**. Linux es la pieza que habla con los componentes y GNU es la pieza que habla contigo.
